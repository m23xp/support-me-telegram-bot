<h3> خطوات التثبيت والتشغيل | Quick Start</h3>

<p><b>1. انسخ المستودع (Clone Repository):</b></p>
<pre>git clone https://github.com/m23xp/support-me-telegram-bot.git</pre>

<p><b>2. ادخل للمجلد (Enter Folder):</b></p>
<pre>cd support-me-telegram-bot</pre>

<p><b>3. ثبت المتطلبات (Install Requirements):</b></p>
<pre>pip install -r requirements.txt</pre>

<p><b>4. الإعداد (Configuration):</b><br>
 افتح ملف <code>bot.py</code> واستبدل <code>TOKEN</code> بالتوكن الخاص بك.</p>

<p><b>5. شغل البوت (Run Bot):</b></p>
<pre>python3 bot.py</pre>
